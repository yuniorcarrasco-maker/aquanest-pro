# Aquanest Pro

This is the aquanest-pro project - a static website for water treatment systems.

## Project Structure

- `index.html` - Main landing page
- `style.css` - Main stylesheet
- `script.js` - Main JavaScript file
- `images/` - Image assets
- `print/` - Print-related resources

## Available Skills

This project is configured with the following skills:

- `tienda-shopify-v2` - For creating and editing Shopify stores

## Development Notes

Use the `/tienda-shopify-v2` skill to manage any Shopify store integration or setup.
